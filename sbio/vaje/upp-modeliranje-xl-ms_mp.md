# Modeliranje proteinskega kompleksa z uporabo XL-MS podatkov

## Namen

Namen vaje je seznanitev z uporabo kemijskih prečnih povezav (XL, angl. *cross-linking*) kot prostorskih omejitev pri modeliranju medproteinskih kompleksov in sicer na primeru modeliranja kompleksa med interlevkinom-7 (IL-7) in njegovim receptorjem. 

V ChimeraX nainstalirajte paket pandas verzije 2.2.3, ki je združljiva z vtičnikom XMAS: `Tools > Command Line Interface`: `devel pip install pandas==2.2.3`
